# GALIKA Architecture

The watchdog is not the primary event runtime.

Event runtime:
- discovers jobs
- canonicalizes/deduplicates
- verifies and qualifies in parallel
- fans in
- prepares application package
- applies through authorized routes
- captures external confirmation
- reconciles delivery
- schedules follow-up
- ingests recruiter responses
- updates learning evidence

Recovery watchdog:
- detects stale READY/RUNNING work
- releases expired leases
- requeues retryable failures
- detects source/route degradation
- reconciles delayed delivery evidence
- surfaces only material user decisions

Secrets remain runtime-only and must not be committed.
